# T0.2 — TypeScript + ESLint + Prettier
> Fase 0 | Pré-req: T0.1 | Próximo: T0.3

Configura as ferramentas de qualidade de código de forma compartilhada no monorepo: TypeScript strict, ESLint com regras para TS+React, e Prettier consistente.

---

## Prompt

```
No monorepo BolsoFirme (Turborepo + npm workspaces), stack Node.js 20 + React 18 + TypeScript 5.
Preciso configurar TypeScript, ESLint e Prettier de forma centralizada.

Gere os arquivos com conteúdo completo:

1. tsconfig.base.json na raiz:
   - strict: true, target: ES2022, module: NodeNext, moduleResolution: Bundler
   - Sem paths locais, apenas as opções base compartilhadas

2. apps/api/tsconfig.json:
   - Extende "../../tsconfig.base.json"
   - Adiciona: outDir: dist, rootDir: src, lib: [ES2022]

3. apps/web/tsconfig.json:
   - Extende "../../tsconfig.base.json"
   - Adiciona: lib: [ES2022, DOM, DOM.Iterable], jsx: react-jsx

4. .eslintrc.json na raiz:
   - Parser: @typescript-eslint/parser
   - Plugins: @typescript-eslint, react (apenas para apps/web)
   - Regras: no-unused-vars como error, @typescript-eslint/no-explicit-any como warn

5. .prettierrc na raiz:
   - singleQuote: true, semi: false, tabWidth: 2, trailingComma: "es5"

6. .prettierignore e .eslintignore excluindo node_modules, dist, .turbo

Inclua os comandos de instalação das dependências (dev) necessárias.
```

---

## Checklist
- [ ] Criar `tsconfig.base.json` na raiz com strict e ES2022
- [ ] Criar `tsconfig.json` em `apps/api` e `apps/web` extendendo o base
- [ ] Instalar ESLint + `@typescript-eslint/parser` + `@typescript-eslint/eslint-plugin` + `eslint-plugin-react`
- [ ] Criar `.eslintrc.json` na raiz e `.prettierrc`
- [ ] Rodar `npm run lint` na raiz e confirmar zero erros
