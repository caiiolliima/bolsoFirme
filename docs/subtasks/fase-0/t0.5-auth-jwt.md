# T0.5 — Autenticação JWT (Registro, Login, Refresh)
> Fase 0 | Pré-req: T0.4 | Próximo: T0.6

Implementa autenticação completa com JWT: registro, login, refresh token e middleware de proteção de rotas. Arquitetura DDD.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma + Zod), implemente autenticação JWT com arquitetura DDD.
Localização: apps/api/src/ com pastas: domain/, application/, infrastructure/, interface/

Endpoints:
- POST /auth/register → cria conta { name, email, password }
  Retorna: { accessToken, refreshToken, user: { id, name, email } }
- POST /auth/login → { email, password }
  Retorna: { accessToken (15min), refreshToken (7 dias) }
- POST /auth/refresh → { refreshToken }
  Retorna: novo { accessToken }
- POST /auth/logout → { refreshToken } — invalida o token no banco

Segurança:
- Senha hasheada com bcryptjs (saltRounds: 10)
- accessToken: JWT com payload { userId, email }, expira em 15m
- refreshToken: UUID aleatório salvo na tabela RefreshToken com expiresAt
- Middleware `authenticate`: extrai Bearer token do header, valida JWT, injeta req.userId

Validação (Zod):
- register: email válido, senha mínimo 8 chars, name não vazio
- Erros retornados em português com status 400

Gere os arquivos completos:
- domain/entities/User.ts e domain/errors/AuthErrors.ts
- application/use-cases/RegisterUser.ts e LoginUser.ts
- infrastructure/repositories/UserRepository.ts (Prisma)
- interface/controllers/AuthController.ts e interface/routes/auth.routes.ts
- interface/middlewares/authenticate.ts
```
