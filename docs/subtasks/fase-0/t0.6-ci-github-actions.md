# T0.6 — CI/CD Básico com GitHub Actions
> Fase 0 | Pré-req: T0.5 | Próximo: T1.1

Configura verificação automática no GitHub: a cada push ou PR na main, roda lint, build e testes. Com cache do Turborepo para builds rápidos.

---

## Prompt

```
No monorepo BolsoFirme (Turborepo + Node.js 20 + React + TypeScript), crie um workflow GitHub Actions.

Arquivo: .github/workflows/ci.yml

Requisitos do workflow:
- Dispara em: push e pull_request para a branch main
- Runner: ubuntu-latest
- Node.js: 20.x

Passos na ordem:
1. actions/checkout@v4
2. actions/setup-node@v4 com node-version: 20 e cache: npm
3. npm ci (instala dependências usando package-lock.json)
4. Cache do Turborepo: usar actions/cache@v4 com chave baseada no hash de turbo.json
5. npm run lint (roda ESLint em todos os packages)
6. npm run build (compila todos os packages com Turborepo)
7. npm run test (roda os testes quando existirem — use continue-on-error: true por enquanto)

Configuração do Turborepo no CI:
- Variável de ambiente TURBO_TEAM e TURBO_TOKEN vazias (remote caching desabilitado por ora)
- Adicionar --no-cache=false no turbo para usar o cache local do step de cache

Gere o arquivo ci.yml completo e pronto para commitar.
```
