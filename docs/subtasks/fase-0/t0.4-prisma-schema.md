# T0.4 — Schema do Banco com Prisma
> Fase 0 | Pré-req: T0.3 | Próximo: T0.5

Define todas as tabelas do BolsoFirme no schema Prisma e roda a primeira migration, criando a estrutura completa no PostgreSQL.

---

## Prompt

```
No projeto BolsoFirme (Node.js + TypeScript + Prisma + PostgreSQL), crie o schema inicial do Prisma.
Arquivo: apps/api/prisma/schema.prisma

Entidades necessárias com todos os campos:

User: id (uuid), email (unique), name, passwordHash, createdAt, updatedAt

Category: id (uuid), userId (FK User), name, color (String, ex: "#FF6B6B"),
  emoji, budgetPercent (Float, opcional), isDefault (Boolean, default false), createdAt

Transaction: id (uuid), userId (FK User), categoryId (FK Category, opcional),
  amount (Decimal, 12,2), type (enum: INCOME | EXPENSE), date (DateTime),
  description (opcional), createdAt

Goal: id (uuid), userId (FK User), name, targetAmount (Decimal), currentAmount (Decimal, default 0),
  deadline (DateTime, opcional), imageUrl (opcional), monthlyContribution (Decimal, opcional),
  term (enum: SHORT | MEDIUM | LONG), isCompleted (Boolean, default false),
  completedAt (opcional), createdAt

Asset: id (uuid), userId (FK User), name, ticker (opcional), type (enum: STOCK | FII | CDB | TREASURY | CRYPTO | OTHER),
  quantity (Decimal), avgPrice (Decimal), currentPrice (Decimal, opcional), createdAt

RefreshToken: id (uuid), token, userId (FK User), expiresAt (DateTime), createdAt

Relacionamentos:
- User (1) → (*) Transactions, Categories, Goals, Assets, RefreshTokens
- Transaction (*) → (1) Category (opcional)

Gere o schema.prisma completo. Depois, mostre os comandos:
- `npx prisma migrate dev --name init` (cria as tabelas)
- `npx prisma generate` (gera o client TypeScript)
```

---

## Checklist
- [ ] Instalar Prisma: `npm install prisma @prisma/client --workspace=apps/api`
- [ ] Rodar `npx prisma init` em `apps/api` para criar o diretório prisma/
- [ ] Escrever o `schema.prisma` com as 6 entidades e enums
- [ ] Rodar `npx prisma migrate dev --name init` — confirmar tabelas criadas
- [ ] Rodar `npx prisma generate` — confirmar client TypeScript gerado
- [ ] Abrir Prisma Studio (`npx prisma studio`) e confirmar todas as tabelas aparecem
