# T0.3 — Docker Compose (PostgreSQL + Prisma Studio)
> Fase 0 | Pré-req: T0.2 | Próximo: T0.4

Sobe o banco de dados PostgreSQL e o Prisma Studio com um único `docker-compose up -d`, sem instalar Postgres na máquina.

---

## Prompt

```
No projeto BolsoFirme, crie a infraestrutura local com Docker Compose.

Gere os seguintes arquivos com conteúdo completo:

1. docker-compose.yml na raiz do projeto:
   Serviço postgres:
   - Imagem: postgres:16-alpine
   - Banco: bolsofirme_db, usuário: bolsofirme_user, senha: bolsofirme_pass
   - Porta: 5432:5432
   - Volume nomeado: postgres_data (dados persistem ao reiniciar)
   - healthcheck com pg_isready

   Serviço prisma-studio:
   - Imagem: ou comando npx prisma studio --port 5555 (via node image)
   - Porta: 5555:5555
   - Depende do postgres estar healthy

2. .env na raiz (nunca commitar — já está no .gitignore):
   DATABASE_URL="postgresql://bolsofirme_user:bolsofirme_pass@localhost:5432/bolsofirme_db"
   NODE_ENV=development
   PORT=3000

3. .env.example na raiz (commitar — template sem valores reais):
   DATABASE_URL="postgresql://USER:PASS@localhost:5432/bolsofirme_db"
   NODE_ENV=development
   PORT=3000

Confirme que .env está no .gitignore e mostre o comando para verificar os containers.
```

---

## Checklist
- [ ] Criar `docker-compose.yml` com postgres:16-alpine e volume persistente
- [ ] Criar `.env` com `DATABASE_URL` completa
- [ ] Criar `.env.example` com chaves mas sem valores reais
- [ ] Confirmar que `.env` está no `.gitignore`
- [ ] Rodar `docker-compose up -d` e verificar com `docker ps`
- [ ] Confirmar PostgreSQL acessível: `docker exec -it [container] psql -U bolsofirme_user -d bolsofirme_db`
- [ ] Abrir `http://localhost:5555` e ver o Prisma Studio (após T0.4)
