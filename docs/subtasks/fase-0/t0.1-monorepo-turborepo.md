# T0.1 — Monorepo Turborepo + Estrutura de Pastas
> Fase 0 | Pré-req: nenhum | Próximo: T0.2

Cria o repositório base do BolsoFirme com Turborepo, estruturando apps/web, apps/api e packages/shared num único monorepo com pipelines de build compartilhados.

---

## Prompt

```
Estou iniciando o projeto BolsoFirme — app de controle financeiro pessoal (freemium, web + mobile futura).
Preciso criar um monorepo com Turborepo usando npm workspaces.

Estrutura alvo:
  apps/web/       → React 18 + Vite + TypeScript (frontend, porta 5173)
  apps/api/       → Node.js 20 + TypeScript + Express (backend, porta 3000)
  packages/shared/→ Tipos TypeScript e schemas Zod compartilhados

Gere os seguintes arquivos com conteúdo completo:
1. package.json raiz com workspaces: ["apps/*", "packages/*"] e scripts: dev, build, lint, test
2. turbo.json com os pipelines build, dev, lint, test (dev sem cache, build dependente de ^build)
3. apps/api/package.json com nome "@bolsofirme/api" e scripts dev/build/lint
4. apps/web/package.json com nome "@bolsofirme/web" e scripts dev/build/lint
5. packages/shared/package.json com nome "@bolsofirme/shared" e exports configurados
6. .gitignore cobrindo node_modules, dist, .turbo, .env

O script dev na raiz deve subir web e api ao mesmo tempo via turbo run dev.
```
