# T3.1 — Backend: CRUD de Metas Financeiras
> Fase 3 | Pré-req: T2.4 | Próximo: T3.2

Endpoints para gerenciar metas financeiras com cálculo automático de projeção de prazo e histórico de aportes.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma + Zod), arquitetura DDD, implemente o CRUD de Metas (Goals).

Endpoints (todos autenticados):
- GET    /goals               → listar metas do usuário (com projeção calculada)
- GET    /goals/:id           → buscar uma meta
- POST   /goals               → criar meta
- PATCH  /goals/:id           → editar meta
- DELETE /goals/:id           → deletar meta
- POST   /goals/:id/contributions → registrar aporte manual

Campos da Goal (POST/PATCH):
- name: string
- targetAmount: number (ex: 30000)
- deadline: string ISO date (opcional)
- imageUrl: string (opcional)
- monthlyContribution: number (opcional — aporte mensal recorrente)

Calcular e retornar junto com cada Goal:
- percentComplete: (currentAmount / targetAmount) × 100
- term: "SHORT" (<1 ano até deadline) | "MEDIUM" (1-3 anos) | "LONG" (>3 anos) — baseado em deadline
- monthsRemaining: Math.ceil((targetAmount - currentAmount) / monthlyContribution) se monthlyContribution > 0
- estimatedCompletion: new Date() + monthsRemaining meses

Tabela GoalContribution no Prisma: id, goalId, amount, date, createdAt.
Quando POST /goals/:id/contributions:
- Somar amount ao currentAmount da meta
- Se currentAmount >= targetAmount → marcar isCompleted=true, completedAt=now()

Schemas Zod em packages/shared/src/schemas/goal.ts.
```
