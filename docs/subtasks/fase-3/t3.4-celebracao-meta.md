# T3.4 — Celebração ao Completar Meta (Confetti + Estado)
> Fase 3 | Pré-req: T3.3 | Próximo: T4.1

Quando o usuário atinge 100% de uma meta, o app celebra com confetti e muda o visual do card. Metas concluídas aparecem numa aba separada.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + canvas-confetti), implemente celebração ao completar meta.

Backend — já feito em T3.1: quando AddContribution detecta currentAmount >= targetAmount, marca isCompleted=true e completedAt=now().

Frontend:

1. Detecção de conclusão no GoalCard:
   - Comparar o percentComplete anterior (ref) com o atual (state)
   - Se anterior < 100% e atual >= 100%: disparar celebração UMA vez
   - Usar useRef para guardar o valor anterior e useEffect para comparar

2. Animação de celebração (canvas-confetti):
   confetti({ particleCount: 150, spread: 90, origin: { y: 0.6 }, colors: ["#FFD700","#00C851","#2196F3"] })
   - Disparar por 3 segundos com requestAnimationFrame (não bloquear o render)

3. Toast especial (react-hot-toast customizado):
   toast.custom(<div className="...">🎉 Parabéns! Meta concluída: [nome]</div>, { duration: 5000 })

4. Visual do GoalCard concluído:
   - Badge "✅ Concluída" no canto superior direito
   - Borda brilhante: ring-2 ring-emerald-400 ring-offset-2
   - Texto "Concluída em [data formatada]" no lugar do prazo estimado
   - Botão "Aportar" some (substituído por "Ver detalhe")

5. Abas na GoalsPage:
   - "Ativas": goals onde isCompleted = false
   - "Concluídas": goals onde isCompleted = true (ordenadas por completedAt desc)

Gere todos os componentes com TypeScript.
```
