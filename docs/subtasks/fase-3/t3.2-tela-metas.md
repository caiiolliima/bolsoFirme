# T3.2 — Tela de Metas e Sonhos (Cards + Criação)
> Fase 3 | Pré-req: T3.1 | Próximo: T3.3

Página com grid de cards visuais de metas, cada um com imagem de fundo, barra de progresso e prazo estimado. Formulário para criar novas metas.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + TanStack Query), crie a página de Metas e Sonhos.
Arquivo: apps/web/src/pages/GoalsPage.tsx

Grid principal:
- Grid responsivo: 1 coluna mobile, 2 colunas md, 3 colunas lg
- Ordenação: metas mais próximas de completar (maior percentComplete) primeiro
- Metas ativas primeiro, depois as concluídas (abas: "Ativas" | "Concluídas")

Componente GoalCard (apps/web/src/components/GoalCard.tsx):
- Se imageUrl: imagem de fundo com gradiente escuro (overlay bg-gradient-to-t from-black/80)
- Nome em destaque (text-white text-xl font-bold)
- "R$ [currentAmount] / R$ [targetAmount]" formatado com Intl.NumberFormat
- Barra de progresso: largura = percentComplete%, cor:
  → cinza (<25%), azul (25-75%), verde (>=75%), esmeralda pulsando ao completar
- Prazo estimado: "~14 meses para concluir" ou "Concluída em Jul/2027"
- Tag de prazo: badge pequeno colorido — curto (verde) | médio (azul) | longo (roxo)
- Botão "Aportar" no rodapé do card (abre ContributionModal)

Modal "+ Nova Meta":
- Campos: nome, valor total (máscara R$), prazo (date, opcional), URL da foto (opcional)
- Preview em tempo real da imagem ao digitar a URL
- Sugestão automática: "Para R$30.000 em 12 meses, aporte mensal: R$2.500"
- Submit: POST /goals → invalidar ["goals"]

Hook: apps/web/src/hooks/useGoals.ts — queryKey: ["goals"]
```
