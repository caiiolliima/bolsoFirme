# T3.3 — Aportes e Projeção de Prazo com Gráfico
> Fase 3 | Pré-req: T3.2 | Próximo: T3.4

Modal de aporte com histórico, página de detalhe da meta e gráfico de linha com evolução real + projeção futura pontilhada.

---

## Prompt

```
No BolsoFirme (Node.js + React 18 + TypeScript + Tailwind + Recharts), crie aportes e projeção de metas.

Backend:
Endpoint: GET /goals/:id/projection (autenticado)
- Simular mês a mês: currentAmount + (monthlyContribution × n) até atingir targetAmount
- Limitar a 120 meses (10 anos)
- Retornar: { history: Array<{date, amount}>, projection: Array<{date, projectedAmount}> }
  history: aportes reais (da tabela GoalContribution) com data e currentAmount acumulado
  projection: pontos futuros mensais até targetAmount

Frontend:
1. Componente ContributionModal (apps/web/src/components/ContributionModal.tsx):
   Props: goal: Goal, onSuccess: () => void
   - Campo: valor do aporte (R$, obrigatório)
   - Checkbox: "Definir como aporte mensal recorrente" → atualiza goal.monthlyContribution
   - Histórico dos últimos 5 aportes (data + valor) em lista compacta
   - Submit: POST /goals/:id/contributions → currentAmount aumenta
   - A barra de progresso no GoalCard anima via CSS transition-all duration-500

2. Página /goals/:id (apps/web/src/pages/GoalDetailPage.tsx):
   - Cards: quantidade aportada, restante, aporte mensal (editável inline)
   - Gráfico de linha (Recharts ComposedChart):
     → Linha sólida: histórico real de aportes (dataKey="amount")
     → Linha tracejada (strokeDasharray="5 5"): projeção futura (dataKey="projectedAmount")
     → Eixo X: datas formatadas como "Mar/26"
     → Tooltip unificado mostrando valor
   - Tabela completa de histórico de aportes (data + valor + acumulado)
   - Botão "+ Nova Compra"

Use queryKey: ["goal", id] e ["goal-projection", id].
```
