# T5.2 — Sistema de Permissões (Admin/Membro) e Contexto de Grupo
> Fase 5 | Pré-req: T5.1 | Próximo: T5.3

Middleware de permissões para grupos, campo groupId opcional em transações e endpoint do dashboard completo para ADMINs.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma), implemente permissões de grupo.

1. Migration Prisma: adicionar campo opcional groupId (FK Group) na tabela Transaction.
   Rodar: npx prisma migrate dev --name add-group-id-to-transaction

2. Middleware requireGroupRole (apps/api/src/interface/middlewares/requireGroupRole.ts):
   Parâmetros: role: "ADMIN" | "MEMBER"
   - Extrair groupId dos params ou body
   - Buscar GroupMember onde userId = req.userId e groupId = groupId
   - Se não encontrar → 403 { error: "NOT_GROUP_MEMBER" }
   - Se role="ADMIN" e GroupMember.role != "ADMIN" → 403 { error: "REQUIRES_ADMIN" }
   - Injetar req.groupMember para uso nos controllers

3. Endpoint GET /groups/:id/dashboard (apenas ADMIN):
   Retornar para o mês informado (?month=YYYY-MM):
   {
     members: Array<{ userId, name, totalExpense, totalIncome }>,
     byCategory: Array<{ categoryId, name, color, total, byMember: { userId, amount }[] }>,
     totalGroupExpense, totalGroupIncome
   }
   Filtrar apenas transações com groupId = :id

4. Atualizar TransactionForm no frontend:
   - Se usuário pertencer a um grupo: mostrar checkbox "Incluir no orçamento do grupo"
   - Se marcado: enviar groupId no body do POST /transactions

Gere middleware, migration e endpoint de dashboard de grupo.
```
