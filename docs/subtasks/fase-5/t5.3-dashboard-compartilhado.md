# T5.3 — Dashboard Compartilhado do Grupo
> Fase 5 | Pré-req: T5.2 | Próximo: T5.4

Tela exclusiva para ADMINs com gastos consolidados de todos os membros, gráfico de barras por membro/categoria e ranking de quem gastou mais.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + Recharts + TanStack Query), crie o Dashboard do Grupo.
Arquivo: apps/web/src/pages/GroupDashboardPage.tsx — rota: /groups/:id/dashboard

Verificar acesso: se usuário não for ADMIN do grupo → redirecionar para /dashboard com toast "Acesso restrito"

Layout:
1. Header: "Família [nome do grupo]" + avatares dos membros (iniciais coloridas) + seletor de mês

2. Cards de resumo do grupo (3 cards):
   - Total de entradas do grupo | Total de saídas | Saldo do grupo

3. Gráfico de barras agrupadas (Recharts BarChart):
   - Eixo X: categorias de gasto
   - Uma barra por membro (cor diferente, extraída do nome via determinístico hashing)
   - Tooltip: "[Membro] em [Categoria]: R$ [valor]"
   - Legenda com nome de cada membro

4. Ranking "Quem gastou mais":
   - Lista ordenada com posição, avatar, nome e total gasto no mês
   - Barra de progresso relativa ao maior gasto

5. Últimas 20 transações do grupo:
   - Avatar + nome do membro | descrição | categoria | valor
   - Filtro dropown: "Todos os membros" + cada membro individualmente

Na AppLayout (sidebar): exibir link "👨‍👩‍👧 Meu Grupo" quando useAuth().user pertencer a um grupo.

Use queryKey: ["group-dashboard", id, month].
```
