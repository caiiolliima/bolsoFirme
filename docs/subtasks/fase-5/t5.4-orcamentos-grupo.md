# T5.4 — Orçamentos Compartilhados por Grupo
> Fase 5 | Pré-req: T5.3 | Próximo: T6.1

ADMINs definem limites por categoria para o grupo inteiro. Os alertas funcionam com a soma dos gastos de todos os membros.

---

## Prompt

```
No BolsoFirme (Node.js + React 18 + TypeScript + Prisma + Tailwind), implemente orçamentos compartilhados de grupo.

Backend:
Novo modelo Prisma: GroupBudget { id, groupId (FK Group), categoryId (FK Category), budgetAmount (Decimal), month (String "YYYY-MM"), createdAt }

Endpoints (todos com requireGroupRole):
- GET  /groups/:id/budgets?month=YYYY-MM → listar orçamentos do mês com gasto atual (soma de todos os membros)
- POST /groups/:id/budgets    → criar/atualizar orçamento de uma categoria para o mês (apenas ADMIN)

Lógica GET /groups/:id/budgets:
Para cada categoria:
  - spent = soma das EXPENSE transactions com groupId=:id e categoryId e month correspondente
  - percentUsed = (spent / budgetAmount) × 100
  - status: "OK" | "WARNING" (>80%) | "EXCEEDED" (>100%)
Reutilizar a mesma lógica de alertas da T2.4.

Frontend:
- Aba "Orçamento" na página do grupo /groups/:id
- Tabela: emoji + categoria | orçamento (editável pelo ADMIN) | gasto atual | status (badge colorido)
- MEMBRO vê a tabela somente leitura
- ADMIN pode clicar no orçamento para editar inline (input) e confirmar com Enter

Componente: apps/web/src/pages/GroupBudgetPage.tsx ou aba dentro de GroupDashboardPage.
Use queryKey: ["group-budgets", id, month].
```
