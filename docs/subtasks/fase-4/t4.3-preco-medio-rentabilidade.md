# T4.3 — Detalhe do Ativo: Histórico e Evolução do Preço Médio
> Fase 4 | Pré-req: T4.2 | Próximo: T4.4

Página de detalhe de um ativo com tabela de histórico de todas as compras e gráfico de linha mostrando como o preço médio evoluiu na sequência das compras.

---

## Prompt

```
No BolsoFirme (Node.js + React 18 + TypeScript + Tailwind + Recharts), crie a página de detalhe do ativo.

Backend:
Endpoint: GET /assets/:id/history (autenticado)
- Retornar lista de compras em ordem cronológica
- Para cada compra, calcular o preço médio acumulado até aquele ponto
- Array<{ id, quantity, price, purchasedAt, avgPriceAfter, totalInvestedAfter }>

Frontend:
Arquivo: apps/web/src/pages/AssetDetailPage.tsx — rota: /investments/:id

1. Header: nome do ativo + ticker em badge + badge colorido do tipo (STOCK/FII/etc.)

2. Cards de métricas (4 cards):
   - Quantidade total
   - Preço médio (calculado das compras)
   - Preço atual (campo inline editável, igual à InvestmentsPage)
   - Rentabilidade total (R$ e %)

3. Tabela de histórico de compras:
   Colunas: Data | Quantidade | Preço Unit. | Valor Total | Preço Médio Após
   Rodapé: linha de totais (quantidade total, custo total)

4. Gráfico de linha (Recharts LineChart):
   - Eixo X: índice de compras ou data formatada
   - Linha: evolução do avgPriceAfter a cada compra (strokeWidth: 2, cor azul)
   - Ponto destacável ao hover (Dot customizado)
   - Tooltip: "Compra #N — Preço médio: R$ X"

5. Botão "+ Nova Compra" (abre modal com campos: quantidade + preço)
   - Preview em tempo real: "Novo preço médio: R$ [calculado]"

Use queryKey: ["asset", id] e ["asset-history", id].
```
