# T4.1 — Backend: CRUD de Ativos de Investimento
> Fase 4 | Pré-req: T3.4 | Próximo: T4.2

Endpoints para gerenciar a carteira de investimentos. Cada nova compra atualiza o preço médio ponderado automaticamente.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma + Zod), arquitetura DDD, implemente o CRUD de Ativos (Assets).

Endpoints (todos autenticados):
- GET    /assets           → listar ativos do usuário (com totais calculados)
- POST   /assets           → adicionar ativo (primeira compra)
- PATCH  /assets/:id       → editar ativo (nome, ticker, currentPrice)
- DELETE /assets/:id       → deletar ativo e histórico de compras
- POST   /assets/:id/purchases → registrar nova compra (recalcular preço médio)
- GET    /assets/summary   → resumo: patrimônio total, alocação por tipo

Campos do Asset (POST): name, ticker?, type (STOCK|FII|CDB|TREASURY|CRYPTO|OTHER), quantity, avgPrice, currentPrice?

Cálculo de preço médio ponderado (POST /assets/:id/purchases):
Body: { quantity: number, price: number }
novoAvg = (asset.quantity × asset.avgPrice + novaQtd × novoPreco) / (asset.quantity + novaQtd)
Atualizar: asset.quantity += novaQtd, asset.avgPrice = novoAvg

Retornar junto com cada Asset:
- totalInvested: quantity × avgPrice
- currentValue: quantity × currentPrice (null se currentPrice não informado)
- profitLoss: currentValue - totalInvested (null se sem currentPrice)
- profitLossPercent: (profitLoss / totalInvested) × 100

Endpoint GET /assets/summary:
- patrimonyByType: Array<{ type, totalInvested, currentValue }>
- totalInvested, totalCurrentValue, totalProfitLoss

Tabela AssetPurchase: id, assetId, quantity, price, purchasedAt, createdAt.
Schemas Zod em packages/shared/src/schemas/asset.ts.
```
