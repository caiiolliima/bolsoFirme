# T2.3 — Divisão Automática do Salário (Regra 50/30/20)
> Fase 2 | Pré-req: T2.2 | Próximo: T2.4

Um assistente que sugere como dividir o salário entre categorias usando a Regra 50/30/20. O usuário vê o preview e confirma antes de salvar.

---

## Prompt

```
No BolsoFirme, implemente a divisão automática do salário por categoria usando a Regra 50/30/20.

Backend (Node.js + TypeScript + Prisma):
Endpoint: POST /categories/auto-distribute (autenticado)
Body: { salary: number, strategy: "50-30-20" }

Lógica da Regra 50/30/20:
- 50% Necessidades → distribuir entre categorias: Moradia (25%), Alimentação (15%), Transporte (10%)
- 30% Desejos → distribuir entre: Lazer (15%), Vestuário (10%), Educação (5%)
- 20% Futuro → distribuir entre: Investimento (12%), Metas/Dívidas (8%)
Mapear pelo campo `name` da categoria (case-insensitive, partial match).
Retornar: Array<{ categoryId, name, suggestedPercent, suggestedValue }>
Salvar os budgetPercent no banco (PATCH em cada categoria).

Frontend (React + Tailwind):
Componente: apps/web/src/components/AutoDistributeModal.tsx

1. Botão "✨ Distribuir automaticamente" na CategoriesPage (abaixo do input de salário)
2. Modal com 3 passos:
   Passo 1: explicação da Regra 50/30/20 em linguagem simples (3 bullets)
   Passo 2: preview das sugestões (tabela: categoria | % sugerido | R$ calculado)
   Passo 3: confirmação "Tudo certo! Os percentuais foram salvos." + fechar
3. Botões: "Cancelar" e "Aplicar sugestões"
4. Após aplicar: invalidar query ["categories"] + os sliders atualizam

Gere backend e frontend completos com TypeScript.
```
