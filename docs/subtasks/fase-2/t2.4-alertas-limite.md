# T2.4 — Alertas de Limite por Categoria
> Fase 2 | Pré-req: T2.3 | Próximo: T3.1

O sistema avisa quando uma categoria está próxima (>80%) ou ultrapassou (>100%) o limite de orçamento. Alertas no dashboard, barras coloridas e badge no header.

---

## Prompt

```
No BolsoFirme, implemente alertas de limite de orçamento por categoria.

Backend (Node.js + TypeScript + Prisma):
Endpoint: GET /categories/alerts?month=YYYY-MM (autenticado)

Para cada categoria do usuário com budgetPercent definido:
- orçamento = salary (do localStorage — passar como query param: ?month=&salary=) × budgetPercent / 100
- gasto = soma das EXPENSE transactions daquela categoria no mês
- percentUsed = (gasto / orçamento) × 100
- status: "OK" (≤70%) | "WARNING" (70–100%) | "EXCEEDED" (>100%)
- exceededBy: gasto - orçamento (apenas quando EXCEEDED)

Retornar: Array<{ categoryId, name, emoji, color, budget, spent, percentUsed, status, exceededBy? }>

Frontend:
1. apps/web/src/hooks/useCategoryAlerts.ts:
   - queryKey: ["category-alerts", month, salary]
   - Busca GET /categories/alerts

2. Na DashboardPage (T1.8) — adicionar seção "Alertas":
   - Só aparece se houver WARNING ou EXCEEDED
   - WARNING: "⚠️ Você usou 85% do orçamento de [emoji] Lazer"
   - EXCEEDED: "🔴 Você ultrapassou [emoji] Alimentação em R$ 150,00"

3. Na CategoriesPage (T2.2):
   - Atualizar barras de progresso: verde (<70%), amarela (70-100%), vermelha (>100%)

4. No AppLayout header — badge vermelho:
   - Número de categorias com status EXCEEDED
   - Fica visível apenas quando count > 0

Gere backend e frontend completos.
```
