# T2.2 — Tela de Categorias e Orçamento
> Fase 2 | Pré-req: T2.1 | Próximo: T2.3

Página onde o usuário define quanto quer gastar em cada área da vida. Slider de percentual, cálculo em tempo real (percentual × salário) e barra de distribuição total.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + TanStack Query), crie a página de Categorias e Orçamento.
Arquivo: apps/web/src/pages/CategoriesPage.tsx

Seção 1 — Input de salário mensal:
- Campo: "Meu salário mensal: R$ ____" com máscara de moeda
- Salvar no localStorage com chave "bf_salary"
- Ao alterar: todos os valores em R$ recalculam imediatamente

Seção 2 — Lista de categorias:
- Renderizar cada categoria com: emoji + bolinha colorida (category.color) + nome
- Slider HTML range (0% a 60%, step 1) para ajustar budgetPercent
- Exibir à direita: "30% — R$ 900,00" (calculado: salary * percent / 100)
- Barra de progresso abaixo: mostra quanto do orçamento foi gasto no mês atual vs limite
  (dados de gasto: GET /categories/alerts?month=YYYY-MM — implementar em T2.4)
- Ao soltar o slider: PATCH /categories/:id com debounce de 500ms (usar useCallback + setTimeout)

Seção 3 — Barra de distribuição total (rodapé fixo ou sticky):
- Mostrar: "[total]% distribuído | [livre]% livre"
- Fica vermelha (text-red-500) se total > 100%

Seção 4 — Modal "+ Nova Categoria" (botão no header):
- Campos: nome (text), emoji (text input, ex: "🍕"), cor (palette de 12 cores predefinidas)
- Submit: POST /categories → invalidar query ["categories"]

Use queryKey: ["categories"] para a lista. Gere TypeScript strict.
```
