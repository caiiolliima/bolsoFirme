# T2.1 — Backend: CRUD de Categorias com Seed Padrão
> Fase 2 | Pré-req: T1.8 | Próximo: T2.2

Endpoints de categorias com regra de soma de percentuais e seed automático das 10 categorias padrão ao registrar um novo usuário.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma + Zod), arquitetura DDD, implemente o CRUD de Categorias.

Endpoints (todos autenticados com middleware authenticate):
- GET    /categories          → listar todas as categorias do usuário (padrão + personalizadas)
- POST   /categories          → criar categoria personalizada
- PATCH  /categories/:id      → editar nome, color, emoji, budgetPercent
- DELETE /categories/:id      → deletar (regra: isDefault=true → retornar 400 "Categorias padrão não podem ser deletadas")

Campos da Category:
- name: string
- color: string (hex, ex: "#FF6B6B")
- emoji: string (ex: "🍔")
- budgetPercent: number | null (0-100)
- isDefault: boolean

Regra de negócio para PATCH:
- A soma de todos os budgetPercent do usuário não pode ultrapassar 100%
- Se ultrapassar → retornar 400 com mensagem em português

Seed de categorias padrão (chamar após RegisterUser use case em T0.5):
Use case SeedDefaultCategories(userId) — criar as 10 categorias:
🏠 Moradia #4A90D9 | 🍔 Alimentação #E74C3C | 🚗 Transporte #F39C12
🎮 Lazer #9B59B6 | 💊 Saúde #2ECC71 | 👕 Vestuário #E67E22
📚 Educação #3498DB | 💰 Investimento #1ABC9C | 💳 Dívidas #E74C3C | 📦 Outros #95A5A6

Schemas Zod em packages/shared/src/schemas/category.ts:
createCategorySchema, updateCategorySchema.

Gere use case, repository, controller e rotas completos.
```
