# T7.2 — Auth e Layout Base Mobile (Tabs + Rotas Protegidas)
> Fase 7 | Pré-req: T7.1 | Próximo: T7.3

Telas de login/registro adaptadas para mobile com SecureStore, Tab Navigator na parte inferior e proteção de rotas com Expo Router.

---

## Prompt

```
No BolsoFirme mobile (React Native + Expo Router v3 + NativeWind + TypeScript), crie auth e layout base.

1. apps/mobile/src/hooks/useAuth.ts:
   - Adaptar do web: usar expo-secure-store ao invés de localStorage
   - SecureStore.setItemAsync("bf_token", token) e SecureStore.getItemAsync("bf_token")
   - Estado: user, token (carregados no mount com useEffect)
   - Funções: login(token, user), logout()
   - isAuthenticated: boolean

2. apps/mobile/app/(auth)/login.tsx:
   - Campos email + senha com KeyboardAvoidingView behavior="padding"
   - SafeAreaView no container externo
   - TouchableOpacity no lugar de <button>
   - Mesma lógica do web: POST /auth/login → useAuth().login() → router.replace("/(app)/dashboard")
   - Mostrar ActivityIndicator enquanto aguarda API
   - Mensagem de erro em texto vermelho abaixo do form
   - Link "Criar conta" com Pressable → router.push("/(auth)/register")

3. apps/mobile/app/(auth)/register.tsx:
   - Campos: nome, email, senha, confirmar senha
   - Mesma validação do web (Zod schema de packages/shared)

4. apps/mobile/app/(app)/_layout.tsx — Tab Navigator:
   - 4 abas na parte inferior (Tabs do Expo Router):
     → dashboard (ícone House de lucide-react-native)
     → transactions (ícone ArrowLeftRight)
     → goals (ícone Target)
     → investments (ícone TrendingUp)
   - tabBarStyle: fundo escuro, aba ativa com cor primária

5. apps/mobile/app/index.tsx:
   - if (isAuthenticated) redirect to /(app)/dashboard
   - else redirect to /(auth)/login

Usar react-native-toast-message para notificações.
```
