# T7.1 — Setup React Native + Expo no Monorepo
> Fase 7 | Pré-req: T6.3 | Próximo: T7.2

Cria o app mobile dentro do monorepo Turborepo, configurado com NativeWind (TailwindCSS para RN), Expo Router e compartilhamento de código via packages/shared.

---

## Prompt

```
No monorepo BolsoFirme (Turborepo + npm workspaces), adicione o app mobile em apps/mobile.

Stack: React Native + Expo SDK 51 + TypeScript + Expo Router v3 + NativeWind v4

Passos e arquivos a gerar:

1. Criar o app:
   cd apps && npx create-expo-app@latest mobile --template blank-typescript
   Configurar package.json com nome "@bolsofirme/mobile"

2. Atualizar turbo.json na raiz:
   Adicionar "apps/mobile" ao campo de workspaces e incluir nos pipelines build e dev

3. Configurar NativeWind v4:
   - Instalar: nativewind tailwindcss
   - tailwind.config.js com content: ["./src/**/*.{ts,tsx}", "./app/**/*.{ts,tsx}"]
   - babel.config.js com preset "nativewind/babel"
   - global.css com @tailwind base/components/utilities

4. Estrutura de pastas em apps/mobile/:
   app/          → páginas Expo Router (file-based routing)
   app/(auth)/   → login.tsx, register.tsx
   app/(app)/    → _layout.tsx (Tab Navigator), dashboard.tsx, transactions.tsx, goals.tsx, investments.tsx
   src/components/, src/hooks/, src/lib/

5. apps/mobile/src/lib/api.ts:
   - Mesma estrutura do web: axios com baseURL (usar env EXPO_PUBLIC_API_URL)
   - Interceptor para Bearer token (usar expo-secure-store ao invés de localStorage)

6. Confirmar que packages/shared é importável (adicionar ao package.json mobile)
```

---

## Checklist
- [ ] Criar app Expo em `apps/mobile` com template TypeScript
- [ ] Adicionar `apps/mobile` ao `turbo.json` e `package.json` workspaces
- [ ] Instalar e configurar NativeWind v4 + `tailwind.config.js`
- [ ] Configurar Expo Router com estrutura `(auth)/` e `(app)/`
- [ ] Criar `src/lib/api.ts` usando expo-secure-store para o token
- [ ] Instalar `@bolsofirme/shared` como dependência local
- [ ] Confirmar que `npx expo start` abre o app no Expo Go (celular ou simulador)
