# T6.1 — Integração Stripe (Checkout + Webhook)
> Fase 6 | Pré-req: T5.4 | Próximo: T6.2

Conecta o app ao Stripe para processar assinaturas. O usuário clica "Assinar", vai para o Stripe, paga e volta como Premium automaticamente via webhook.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma), integre Stripe para assinaturas (plano Premium).

Migration Prisma — adicionar campos no User:
- stripeCustomerId: String? (nullable)
- plan: Enum { FREE, PREMIUM } (default FREE)
- planExpiresAt: DateTime? (nullable)

Instalar: npm install stripe --workspace=apps/api

Variáveis .env a adicionar:
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PRICE_MONTHLY=price_... (R$19,90/mês)
STRIPE_PRICE_ANNUAL=price_...  (R$159,90/ano)
APP_URL=http://localhost:5173

Endpoints:
- POST /billing/checkout → criar Stripe Checkout Session
  Body: { priceId: string }
  Retornar: { checkoutUrl: string }
  - Se usuário não tem stripeCustomerId → criar Customer no Stripe e salvar
  - successUrl: APP_URL/billing/success?session_id={CHECKOUT_SESSION_ID}
  - cancelUrl: APP_URL/pricing

- POST /billing/webhook → receber eventos Stripe (RAW body — usar express.raw())
  Verificar assinatura: stripe.webhooks.constructEvent(body, sig, STRIPE_WEBHOOK_SECRET)
  Eventos a tratar:
  - checkout.session.completed → marcar user.plan = PREMIUM
  - customer.subscription.deleted → marcar user.plan = FREE
  - invoice.payment_failed → log (não punir imediatamente)

- GET /billing/portal → criar Stripe Customer Portal Session e retornar { portalUrl }
- GET /billing/status → retornar { plan, planExpiresAt }

Segurança: a rota /billing/webhook deve usar express.raw() e NÃO usa o middleware JSON padrão.
```
