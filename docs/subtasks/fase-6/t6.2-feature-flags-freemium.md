# T6.2 — Feature Flags: Limites do Plano Gratuito
> Fase 6 | Pré-req: T6.1 | Próximo: T6.3

Implementa as restrições para usuários FREE. Ao tentar usar um recurso Premium, vê um modal de upgrade. Locks visuais discretos nas funcionalidades bloqueadas.

---

## Prompt

```
No BolsoFirme (Node.js + React 18 + TypeScript + Tailwind), implemente os gates do plano freemium.

Backend — middlewares (apps/api/src/interface/middlewares/):

1. requirePlan.ts:
   Parâmetros: requiredPlan: "PREMIUM"
   - Buscar user pelo req.userId e verificar user.plan
   - Se plan != requiredPlan → 403 { error: "PLAN_REQUIRED", requiredPlan }

2. requireResourceLimit.ts:
   Parâmetros: resource: "categories" | "goals", limit: number
   - Contar registros existentes do usuário
   - Se count >= limit → 403 { error: "LIMIT_REACHED", resource, limit, current: count }

Aplicar nos endpoints (apenas para plano FREE):
- POST /categories → requireResourceLimit("categories", 3)
- POST /goals → requireResourceLimit("goals", 2)
- GET /transactions → se user.plan=FREE: adicionar where: date >= subMonths(now, 3)
- POST /categories/auto-distribute → requirePlan("PREMIUM")
- GET /assets (e todos /assets routes) → requirePlan("PREMIUM")
- POST /groups → requirePlan("PREMIUM")

Frontend:

1. Hook usePlan() (apps/web/src/hooks/usePlan.ts):
   - Chama GET /billing/status
   - Retorna: { plan, isPremium, limits: { categories: 3, goals: 2, historyMonths: 3 } }

2. Componente PremiumGate (apps/web/src/components/PremiumGate.tsx):
   Props: feature: string, children: ReactNode
   - Se isPremium → renderiza children normalmente
   - Se FREE → renderiza modal de upgrade (overlay sobre o conteúdo bloqueado)
   - Modal: "🔒 Este recurso é exclusivo do Premium" + [feature descrito] + botão "Assinar agora"

3. Ícone 🔒 discreto (text-xs, opacity-50) nos itens da sidebar bloqueados para FREE.
```
