# T6.3 — Onboarding Multi-step e Página de Planos
> Fase 6 | Pré-req: T6.2 | Próximo: T7.1

Fluxo de boas-vindas para novos usuários (salário + categorias + primeira meta) e página de preços com comparação FREE vs Premium.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + TanStack Query), crie o onboarding e a página de planos.

Backend:
- Migration: adicionar campo onboardingCompletedAt: DateTime? no User
- Endpoint PATCH /users/me/onboarding-complete → marcar onboardingCompletedAt = now()
- Incluir onboardingCompletedAt no retorno de GET /auth/login e /auth/register

Frontend:

1. Componente OnboardingFlow (apps/web/src/components/OnboardingFlow.tsx):
   Disparar quando user.onboardingCompletedAt === null após login
   4 passos com barra de progresso visual:
   Passo 1: "Bem-vindo ao Bolso Firme! 👋" + input de salário mensal (salvar no localStorage "bf_salary")
   Passo 2: Sliders de categorias com sugestão 50/30/20 pré-carregada (reutilizar AutoDistributeModal)
   Passo 3: "Crie sua primeira meta!" (campos: nome + valor, opcional — botão "Pular")
   Passo 4: "Tudo pronto! Seu controle financeiro começa agora. 🚀" + botão "Ir para o dashboard"
   Ao concluir: PATCH /users/me/onboarding-complete → redirecionar para /dashboard

2. Página PricingPage (apps/web/src/pages/PricingPage.tsx) — rota: /pricing:
   Cards lado a lado:
   - Gratuito: R$ 0, lista de recursos com ✓ e ✗
   - Premium: R$ 19,90/mês ou R$ 159,90/ano (toggle mensal/anual), "2 meses grátis" badge no anual
   Tabela de comparação: transações ilimitadas, categorias (3 vs ilimitadas), metas (2 vs ilimitadas), histórico (3 meses vs ilimitado), carteira de investimentos, modo família
   Botão "Assinar agora": POST /billing/checkout com priceId selecionado → redirecionar para checkoutUrl
   Se já for Premium: mostrar "✅ Você já é Premium" + botão "Gerenciar assinatura" → GET /billing/portal

Incluir link /pricing no AppLayout (rodapé da sidebar).
```
