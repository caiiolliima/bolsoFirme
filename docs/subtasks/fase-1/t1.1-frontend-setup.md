# T1.1 — Setup Frontend (React + Vite + Tailwind + Router + TanStack Query)
> Fase 1 | Pré-req: T0.6 | Próximo: T1.2

Configura toda a base do frontend de uma vez: React 18 no Vite, Tailwind, React Router v6, TanStack Query e axios com interceptor de token.

---

## Prompt

```
Configure o frontend do BolsoFirme em apps/web (já existe como package no monorepo Turborepo).
Stack: React 18 + TypeScript + Vite + Tailwind CSS + React Router v6 + TanStack Query v5

Gere os arquivos com conteúdo completo:

1. Instalar e configurar Tailwind CSS:
   - tailwind.config.js com content: ["./src/**/*.{ts,tsx}"]
   - apps/web/src/index.css com @tailwind base/components/utilities

2. apps/web/src/main.tsx:
   - QueryClientProvider com QueryClient (staleTime: 1 min, retry: 1)
   - BrowserRouter envolvendo o App

3. apps/web/src/App.tsx:
   - Rotas públicas: /login, /register
   - Rotas protegidas (envolvidas por PrivateRoute): /dashboard, /transactions, /categories, /goals, /investments
   - Rota padrão "/" redireciona para /dashboard

4. apps/web/src/lib/api.ts:
   - Instância axios com baseURL: import.meta.env.VITE_API_URL ?? "http://localhost:3000"
   - Interceptor request: adiciona Authorization: Bearer [token do localStorage]
   - Interceptor response: se 401, limpa localStorage e redireciona para /login

5. Estrutura de pastas em src/: pages/, components/, hooks/, lib/, types/

Inclua os comandos de instalação de todas as dependências.
```

---

## Checklist
- [ ] Instalar Tailwind CSS e configurar `tailwind.config.js` + `index.css`
- [ ] Instalar React Router v6 (`react-router-dom`) e configurar rotas em `App.tsx`
- [ ] Instalar TanStack Query v5 (`@tanstack/react-query`) e configurar `QueryClientProvider`
- [ ] Instalar axios e criar `src/lib/api.ts` com interceptores
- [ ] Criar estrutura de pastas: `pages/`, `components/`, `hooks/`, `lib/`, `types/`
- [ ] Criar `.env` em `apps/web` com `VITE_API_URL=http://localhost:3000`
- [ ] Confirmar que `npm run dev` abre o app em `http://localhost:5173`
