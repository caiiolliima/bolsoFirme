# T1.7 — Importação de Extrato OFX e CSV
> Fase 1 | Pré-req: T1.6 | Próximo: T1.8

Permite ao usuário baixar o extrato do banco e importar no app. O backend lê o arquivo e cria as transações automaticamente, ignorando duplicatas.

---

## Prompt

```
No BolsoFirme, implemente importação de extratos OFX e CSV.

Backend (Node.js + TypeScript + Express + Prisma):
Endpoint: POST /transactions/import
- Aceita: multipart/form-data com campo "file" (usar multer, armazenar em memória)
- Formato OFX: usar biblioteca `ofx-js` — extrair DTPOSTED, TRNAMT, MEMO de cada STMTTRN
- Formato CSV: usar `csv-parse/sync` — colunas esperadas: data, valor, descricao
  Aceitar variações de cabeçalho: "Data"/"data", "Valor"/"valor", "Histórico"/"descricao"
- Para cada transação do arquivo:
  → Deduplicação: checar se já existe transação com mesmo userId + amount + date + description
  → Se existe → contador ignorados++
  → Se não existe → criar no banco (type: EXPENSE se amount < 0, INCOME se > 0)
- Retornar: { importados: number, ignorados: number, erros: number, detalhes: string[] }

Frontend (React + Tailwind + TanStack Query):
Componente: apps/web/src/components/ImportModal.tsx
- Botão "Importar extrato" na TransactionsPage abre o modal
- Área de drag-and-drop (aceita .ofx e .csv) ou clique para selecionar arquivo
- Preview: "X transações encontradas no arquivo"
- Botão "Importar" → POST /transactions/import → mostra resultado com toast
- Após sucesso: invalidar query ["transactions"] + fechar modal

Segurança: validar extensão e tamanho máximo (5MB) no backend.
```
