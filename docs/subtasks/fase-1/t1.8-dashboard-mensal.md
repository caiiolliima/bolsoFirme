# T1.8 — Dashboard Mensal (Gráfico de Rosca + Resumo)
> Fase 1 | Pré-req: T1.7 | Próximo: T2.1

Tela principal do app: cards de entradas/saídas/saldo, gráfico de rosca por categoria e top 5 categorias do mês. Desbloquia o valor real do MVP.

---

## Prompt

```
No BolsoFirme (Node.js + Express + Prisma | React 18 + TypeScript + Tailwind + Recharts + TanStack Query), crie o Dashboard principal.

Backend:
Endpoint: GET /dashboard/summary?month=YYYY-MM (ex: 2026-03)
- Usar userId do JWT para filtrar
- Retornar:
  {
    totalIncome: number,       // soma de INCOME no mês
    totalExpense: number,      // soma de EXPENSE no mês
    balance: number,           // totalIncome - totalExpense
    byCategory: Array<{        // apenas EXPENSE por categoria
      categoryId, name, color, emoji, total, percent
    }>
  }
- Usar Prisma groupBy para agregar por categoryId

Frontend:
Arquivo: apps/web/src/pages/DashboardPage.tsx

1. Seletor de período no topo: ← [Março 2026] → (botões de mês)

2. 3 cards de resumo em linha:
   - ENTRADAS: valor em verde | SAÍDAS: valor em vermelho | SALDO: positivo=verde, negativo=vermelho

3. Gráfico de rosca (Recharts PieChart innerRadius={60}):
   - Fatia por categoria, cor = category.color
   - Tooltip: "[emoji] [nome] — R$ [valor] ([percent]%)"
   - Legenda abaixo com todos os nomes

4. Lista top 5 categorias que mais gastou:
   - Barra de progresso colorida (largura = percent do total gasto)
   - Nome + emoji + valor + percentual

5. Botão flutuante "+ Lançar" canto inferior direito

Hook: apps/web/src/hooks/useDashboardSummary.ts — queryKey: ["dashboard", month]
```
