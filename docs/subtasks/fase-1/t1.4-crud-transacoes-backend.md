# T1.4 — Backend: CRUD de Transações
> Fase 1 | Pré-req: T1.3 | Próximo: T1.5

Cria os endpoints de transações financeiras com isolamento por `userId`, validação Zod e arquitetura DDD. É a funcionalidade central do app.

---

## Prompt

```
No BolsoFirme (Node.js + Express + TypeScript + Prisma + Zod), arquitetura DDD, implemente o CRUD de Transações.
Use o middleware `authenticate` (já existe de T0.5) em todas as rotas.

Endpoints (todos autenticados via Bearer token):
- POST   /transactions       → criar transação
- GET    /transactions       → listar com filtros: ?startDate=&endDate=&categoryId=&type=&page=&limit=
- GET    /transactions/:id   → buscar uma transação
- PATCH  /transactions/:id   → editar campos parcialmente
- DELETE /transactions/:id   → deletar

Campos do body (POST/PATCH):
- amount: número positivo (Decimal)
- type: "INCOME" | "EXPENSE"
- categoryId: UUID (opcional)
- date: string ISO (ex: "2026-03-11")
- description: string (opcional, max 255 chars)

Regras de negócio:
- Transação pertence ao userId extraído do JWT — nunca ao body
- GET /transactions/:id deve retornar 404 se não pertencer ao usuário logado
- PATCH/DELETE também retornam 404 se transação não for do usuário

Schemas Zod em packages/shared/src/schemas/transaction.ts:
- createTransactionSchema, updateTransactionSchema (todos campos opcionais)

Gere os arquivos: domain/entities/Transaction.ts, application/use-cases/ (Create, List, Update, Delete),
infrastructure/TransactionRepository.ts, interface/TransactionController.ts, interface/routes/transaction.routes.ts
```
