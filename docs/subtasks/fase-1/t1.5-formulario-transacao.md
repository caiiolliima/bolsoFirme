# T1.5 — Formulário de Lançamento de Transação
> Fase 1 | Pré-req: T1.4 | Próximo: T1.6

Tela rápida para registrar entradas e saídas. Toggle ENTRADA/SAÍDA, máscara de moeda em tempo real e reconhecimento básico de padrão na descrição.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + TanStack Query + React Hook Form + Zod), crie o formulário de lançamento de transação.

Arquivo: apps/web/src/components/TransactionForm.tsx
Props: onSuccess: () => void, initialData?: Transaction (para modo edição)

Campos do formulário:
1. Tipo: toggle visual ENTRADA (verde) / SAÍDA (vermelho) — clique alterna entre os dois
2. Valor: input numérico com máscara R$ — ao digitar "15000" exibe "R$ 150,00" em tempo real
3. Categoria: <select> populado por GET /categories via TanStack Query
4. Data: <input type="date"> com default = hoje (new Date().toISOString().split("T")[0])
5. Descrição: <input type="text"> opcional

Reconhecimento de padrão na descrição (useEffect ao alterar descrição):
- Contém "ifood", "rappi", "ubereats" → pré-selecionar categoria "Alimentação"
- Contém "uber", "99pop", "combustível" → pré-selecionar "Transporte"
- Case-insensitive

Comportamento ao submeter:
- Modo criação: POST /transactions via useMutation
- Modo edição: PATCH /transactions/:id via useMutation
- Sucesso: invalidar queryKey ["transactions"] no QueryClient + chamar onSuccess()
- Erro: toast de erro com react-hot-toast
- Loading: botão "Salvar" com spinner durante a requisição

Validação Zod: amount > 0, type obrigatório. Use zodResolver do react-hook-form.
```
