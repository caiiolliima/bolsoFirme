# T1.6 — Lista de Transações com Filtros
> Fase 1 | Pré-req: T1.5 | Próximo: T1.7

Página que lista todas as transações agrupadas por data, com filtros de período, tipo e categoria, e ações de editar/deletar.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + TanStack Query), crie a página de listagem de transações.
Arquivo: apps/web/src/pages/TransactionsPage.tsx

Layout:
1. Header: título "Transações" + botão "+ Nova Transação" (abre TransactionForm em modal)
2. Barra de filtros (abaixo do header):
   - Período: seletor de mês/ano com botões ← mês atual →
   - Tipo: botões toggle Todos | Entradas | Saídas
   - Categoria: <select> com "Todas" + lista de categorias (GET /categories)
3. Lista de transações agrupadas por data:
   - Cabeçalho de grupo: "Hoje — 11/03" ou "11/03/2026"
   - Cada item: emoji da categoria + descrição (ou "Sem descrição") + valor + data
   - Valor: verde com "+" para INCOME, vermelho com "-" para EXPENSE
   - Clique no item: abre TransactionForm em modo edição
   - Botão lixeira: abre modal de confirmação "Deseja deletar esta transação?"
4. Paginação: botão "Carregar mais" ao final (page + 1, acumular resultados)

Hook customizado apps/web/src/hooks/useTransactions.ts:
- Parâmetros: { month: string, type?: "INCOME"|"EXPENSE", categoryId?: string, page: number }
- Monta a query string e chama GET /transactions
- Retorna: { transactions, isLoading, fetchNextPage }

Use TanStack Query com queryKey: ["transactions", filters].
```
