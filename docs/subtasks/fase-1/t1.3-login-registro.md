# T1.3 — Telas de Login e Registro
> Fase 1 | Pré-req: T1.2 | Próximo: T1.4

Primeiras telas reais do app. O usuário preenche email/senha, o app chama a API, salva o token e redireciona para o dashboard.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind + React Hook Form + Zod + TanStack Query), crie as telas de Login e Registro.

Gere os arquivos completos:

1. apps/web/src/pages/LoginPage.tsx:
   - Campos: email + senha
   - Validação Zod: emailSchema (email válido), passwordSchema (não vazio)
   - Submit: POST /auth/login via useMutation do TanStack Query
   - Sucesso: chamar useAuth().login(token, user) → navegar para /dashboard
   - Erro: mostrar mensagem em vermelho abaixo do form ("E-mail ou senha incorretos")
   - Loading: botão desabilitado com spinner (animate-spin) durante requisição
   - Link "Não tem conta? Criar conta" → /register
   - Layout: centralizado na tela, card bg-gray-800 com shadow, logo "Bolso Firme" no topo

2. apps/web/src/pages/RegisterPage.tsx:
   - Campos: nome, email, senha, confirmar senha
   - Validação Zod: nome não vazio, email válido, senha mínimo 8 chars, senhas iguais
   - Submit: POST /auth/register → POST /auth/login automático → navegar para /dashboard
   - Loading state no botão
   - Link "Já tem conta? Entrar" → /login

3. apps/web/src/types/auth.ts:
   - Tipos: LoginRequest, RegisterRequest, AuthResponse { accessToken, refreshToken, user }

Use react-hook-form com zodResolver. Gere TypeScript strict, sem any.
```

---
