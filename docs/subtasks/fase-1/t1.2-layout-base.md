# T1.2 — Layout Base (Sidebar, Header, Rotas Protegidas)
> Fase 1 | Pré-req: T1.1 | Próximo: T1.3

Cria o esqueleto visual do app autenticado: sidebar de navegação, header com nome do usuário, e o hook/componente que redireciona para login se não autenticado.

---

## Prompt

```
No BolsoFirme (React 18 + TypeScript + Tailwind CSS + React Router v6 + lucide-react), crie o layout base.

Gere os arquivos completos:

1. apps/web/src/hooks/useAuth.ts:
   - Estado: user ({ id, name, email } | null) e token (string | null) do localStorage
   - Funções: login(token: string, user: User) → salva no localStorage
   - Função: logout() → limpa localStorage + redireciona para /login
   - isAuthenticated: boolean (!!token)
   - Usar localStorage keys: "bf_token" e "bf_user"

2. apps/web/src/components/PrivateRoute.tsx:
   - Lê token via useAuth()
   - Se não autenticado → <Navigate to="/login" replace />
   - Se autenticado → renderiza <AppLayout><Outlet /></AppLayout>

3. apps/web/src/components/AppLayout.tsx:
   - Sidebar fixa à esquerda (240px) com links usando NavLink do React Router:
     → /dashboard (LayoutDashboard icon), /transactions (ArrowLeftRight icon),
     → /categories (Tag icon), /goals (Target icon), /investments (TrendingUp icon)
   - Link ativo com fundo diferenciado (classe CSS diferente via NavLink isActive)
   - Header no topo: nome do usuário logado (do useAuth) + botão Logout
   - Área de conteúdo principal com overflow-auto
   - Design dark: sidebar bg-gray-900, header bg-gray-800, conteúdo bg-gray-950

Gere TypeScript strict, sem any.
```
